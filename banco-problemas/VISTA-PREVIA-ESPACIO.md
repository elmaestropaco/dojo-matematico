# Volumenes y geometria espacial

40 plantillas: diez contextos para cuatro estructuras. Las cantidades cambian durante el juego. Los dibujos son esquemas, no estan a escala.

## Volumen de un cubo: la biblioteca
ID: espacio-1-1

En la actividad «La biblioteca» estudian un cubo. Cada borde o arista mide 28 cm. ¿Qué volumen tiene la figura, en cm³?

- 28 × 28 = 784 cm² de base
- 784 × 28 = 21952 cm³

Respuesta: **21952 cm³**.
