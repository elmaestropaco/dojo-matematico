# 42 plantillas: divisiones

Contenido editable: divisiones.json. Los marcadores entre llaves son variables.

## 1. Repartir caramelos
ID: division-001 | Dificultad: facil

Para una fiesta tienen {cantidadA} {unidadA}. Reparten esa cantidad por igual entre {cantidadB} {unidadB}. ¿Cuántos caramelos recibe cada niño?

| Variable | Valores o significado |
| --- | --- |
| {cantidadA} | Cantidad total o número de grupos: de 1 a 9999. |
| {cantidadB} | Cantidad por grupo o número de grupos: de 1 a 99. |
| {unidadA} | caramelo / caramelos, segun cantidadA. |
| {unidadB} | niño / niños, segun cantidadB. |

### Ejemplo resuelto

Para una fiesta tienen 24 caramelos. Reparten esa cantidad por igual entre 6 niños. ¿Cuántos caramelos recibe cada niño?

- Repartimos en partes iguales: 24 ÷ 6 = 4.

Respuesta: **4 caramelos**.
